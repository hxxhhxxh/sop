B

九步工序卡

深色卡为关键工序，偷懒必返工
01软件下载Setup
  1. DeepSeek — 改写故事、三视图 / 分镜 / 封面 / 发布提示词
  2. 豆包 — 三视图、封面图、分镜视频（建议备多账号）
  3. 剪映 — 配音、剪辑、字幕、封面排版、导出
  4. 微信小程序 — 文案提取神器 + 去水印（金丝雀去水印）
  5. 手机便签 — 断句与镜头计数
文案图像后期
02故事生成抖快 · 小程序 · DS
  1. 抖音 / 快手搜「民间故事」，选高播放爆款 → 转发 → 复制链接
  2. 微信「文案提取神器」粘贴链接 → 提取视频原文案
  3. DeepSeek 输入：原文案 + 改编指令 + 改编思路
  4. 改编思路：换人物（书生→屠户 / 货郎 / 渔夫）换场景（破庙→老宅 / 坟地 / 荒村）
产出 · 改写故事文案

红线 只借结构与母题，人物场景细节全部重写，避免搬运判定。

03断句优化手机便签 · 人工
  1. 把改写文案粘进便签，人工逐句切分
  2. 23–45 字 → 10 秒镜头（首选，主力档）
  3. ≤ 22 字 → 5 秒镜头（仅用于前后割裂的单句）
  4. > 45 字 → 必须拆分（硬性规则）
  5. 每句末尾加句号 + 单独换行 → 便签序号功能编号 → 得总镜头数
产出 · 带序号镜头表校对语病

为何手工 顺带修正 AI 改写的生硬句；提前锁定镜头，大幅减少后期返工与补镜头。

04主角三视图DS + 豆包
  1. DeepSeek：改写文案 + 三视图指令 → 人物三视图文案
  2. 豆包生图参数：模型 4.5 · 9:16 · 人像摄影
  3. 只做 2–3 个高频主角，次要配角不做
  4. 风控关键：发送指令「转素描图」，保存素描图备用
产出 · 角色素描参考图

双重作用 既规避真人图审核风险，又是 Step 6 保证人物统一的唯一参考源。

05动态分镜文案DeepSeek
  1. DeepSeek 开新对话 → 粘贴专属动态分镜指令
  2. 粘贴已断句完成的完整故事文案
  3. 发送 → AI 按句号自动拆分，输出标准化单镜头提示词
  4. 按分镜序号逐条复制留存
产出 · 逐镜头提示词

注意 手机剪贴板通常最多 15 组，分镜多时分批处理或转存便签。

06视频生成豆包 · 去水印
  1. 模型：额度足选 Fast（画质好，约日 3 条）；额度紧选 Mini（约日 50 秒）
  2. 画幅 9:16 竖屏；时长匹配该镜头字数（5s / 10s）
  3. 点「+」上传对应角色素描参考图
  4. 长按视频 → 分享 → 复制链接 → 去水印小程序解析保存
  5. 务必按分镜顺序命名，剪辑时免于重排
产出 · 无水印竖屏片段
07视频剪辑剪映
  1. 开始创作 → 按分镜顺序勾选 → 勾高清导入
  2. 文本 → 新建文本 → 粘贴文案 → 选不分句（单次 ≤ 500 字）
  3. 文本朗读选说书音色（沉稳 / 深度解说 / 古风男主），1.0–1.15 倍速；文本框拖出画面外，只留配音轨
  4. 音画同步：画面长则裁尾，短则轻微变速；每段结尾对齐语气句空白
  5. 音频 → 音乐 → 古风纯音乐铺满，音量 10–15
  6. 字幕 → 开始识别；字号 10–15，白 / 黄色；加小字「本视频由 AI 制作，故事纯属虚构」
  7. 导出 1080P · 60 帧，码率格式默认
产出 · 成片

变速红线 幅度控制在 ±15% 内，画面速度须接近正常人节奏。

08封面制作DS + 豆包 + 剪映
  1. DeepSeek 输入封面提示词 + 构图 / 风格构思 → 输出封面描述，全选复制
  2. 豆包生图：比例 3:4 · 风格人像摄影 → 保存满意图
  3. 剪映导入 → 比例设 3:4 → 文本加主标题 + 副标题
  4. 选民间故事风格字体，调大小 / 位置 / 颜色 → 全屏预览 → 截图保存
  5. 存为封面模板，后续换图换字复用
产出 · 3:4 自制封面模板可复用
09作品发布DS + 抖音
  1. DeepSeek 粘贴发布文案指令 → 生成标题主题 + 正文 → 复制到抖音编辑区
  2. 抖音底部「+」上传成片
  3. 「更换封面」→ 上传 3:4 自制封面
  4. 添加 5 个高播放话题
  5. 勾选「内容由 AI 生成」自主声明

F

风控 · 效率 · 质量

三层风控叠加，缺一不可
Risk Control · 三道闸
  1. 1源头 — 真人风格图统一「转素描图」再用于生视频
  2. 2成片 — 片内小字标注「AI 制作 / 纯属虚构」
  3. 3平台 — 发布勾选「内容由 AI 生成」
  4. 4内容 — 换人物 + 换场景，不做同题材同人物复述
Efficiency · 五个提速点
  1. ·封面做成模板，只换图换字 — 单条省约 15 分钟
  2. ·素描参考图按角色归档，同 IP 系列持续复用
  3. ·断句阶段一次定死镜头数，避免 Step 6 回头补生成
  4. ·豆包多账号轮换，拆开生视频额度瓶颈
  5. ·分镜文案批量存便签，不依赖剪贴板
Quality · 三条判断
  1. ·开头 3 秒必须是全片最强钩子，必要时把高潮镜头前置
  2. ·以 10 秒镜头为主，5 秒镜头过多会显得碎
  3. ·变速幅度控制在 ±15% 内，超过会明显违和

整套方法的机关在 Step 3：把文案编译成镜头表。镜头数一旦确定，Step 6–7 便只是流水线执行。
